Inline math: \(a^2 + b^2 = c^2\).

Display math:

$$
\frac{1}{2} + \frac{1}{3} = \frac{5}{6}
$$

An alternative display delimiter:

\[
\sum_{n=1}^{3} n = 6
\]

Prices such as $10 and $20 remain ordinary text.

Math inside a code block is shown literally:

```tex
\(a^2 + b^2 = c^2\)
```
